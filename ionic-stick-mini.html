Overview

전체 디자인 프로세스를 주도한 ODM 프로젝트

저주파·온열·LED로 신체 전반을 케어하는 복합 의료가전 ODM 프로젝트입니다. 제품디자인과 기구 설계, UX 기획에 주도적으로 참여했습니다.

메인 PCB에 연결되는 각 부품 배치와 케이블 경로, 하우징 조립 구조의 설계 초안을 직접 기획했고, 이를 토대로 엔지니어와 소통하며 촉박한 일정 안에 최종 디자인 목업을 완성했습니다.

Layout · 핵심

정돈된 사용성을 위한 배선 루트 기획

고전력 복합 의료가전 특성상 핀 수가 많고 두꺼운 케이블을 사용합니다. LED·저주파·온열로 두꺼워진 각 어플리케이터의 케이블 두께와 긴 길이를 고려해, 효율적인 조립성을 유지하면서도 정돈된 배선 루트를 직접 기획했습니다.

Tower Design

딱딱한 의료기기에서 벗어난 조형물 같은 가전

Image
A~E 데스크탑/타워 시안 5종 렌더 + 2D 스케일업 검증
원본 P.22

여러 어플리케이터가 연결될 타워 본체는, 기존의 딱딱한 의료 장비가 아니라 인테리어에 녹아드는 조형물 같은 레이아웃을 지향했습니다. 중·장년층 대상인 만큼 날카로운 엣지 대신 부드러운 볼륨을 중심으로 전개했고, 데스크탑 형태의 D안을 고도화 방향으로 선정했습니다.

실사이즈를 2D·3D 프린팅으로 출력해 정확한 스케일감과 사용성을 검증하며, 더 사용자 친화적인 구조·크기로 디자인을 고도화했습니다.

솔직한 회고

[‘조형물 같은 가전’이라는 의도와 실제 결과 사이에 남은 간극, 또는 일정·구조상 타협한 부분을 1문장으로 채워주세요 — 정직한 회고가 오히려 강점이 됩니다]

Applicators

정돈된 이미지를 연출하는 인체공학적 디자인

보관 시에도 정돈된 실루엣이 유지되도록, 저주파 손봉·원형 패드에는 두 세트가 맞닿을 때 정렬되는 자석 부착 구조를 적용했습니다. 복합 자극 복부 벨트는 25도 중앙 곡선 하우징과 탄성 우레탄 벨트로 착용감을 높였고, 60–80도 경도의 여러 샘플링을 통해 가장 부드러운 착용감의 경도를 찾았습니다.

UX / UI

중·장년층을 고려한 Fast Mode 물리 버튼

터치에 익숙지 않은 중·장년층을 고려해, 자주 쓰는 기능을 위한 Fast Mode 물리 버튼을 함께 배치했습니다. 차량 인포테인먼트처럼 설치 기사·가족이 옵션을 설정해두면 혼자서도 손쉽게 동작할 수 있습니다.

15인치 터치 LCD의 동작 시나리오는 연령과 무관하게 직관적으로 이해되도록 구성하는 데 집중했습니다.
